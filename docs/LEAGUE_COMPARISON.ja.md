# リーグを比較する

*[English](LEAGUE_COMPARISON.md)*

ここ以外の文書は1つの連盟だけを測っています。この文書はそれを他と並べます。**1つのリーグから出た数字は、同じ測り方をした別のものが無いかぎり何も意味しない**からです。

```bash
togakuren compare
togakuren compare --reference docs/reference-leagues.json
```

**ここでいう「部」はシーズンをまたいで同じものではありません。** 2021年から2026年の
あいだに大会は3回作り直されており、2022年の「2部」にいたクラブ群は、2026年に同じ名前が
指す母集団ではありません。以下の数値はすべて1シーズン×1つの部の内側で測っており、
その単位は正しいものです。ただし列を縦に読んで傾向とみなすと、再編をまたいで読むことに
なります。会計は [LEAGUE_STRUCTURE.ja.md](LEAGUE_STRUCTURE.ja.md) にあります。

## 2つの量

**戦力差。** Noll-Scully比は、観測された勝率のばらつきを「全チームが同じ強さだった場合にそのシーズン数で生じるばらつき」で割ったものです。標準的な指標ですが、**ここでは誤答します。** 大学のシーズンは1チーム13〜21試合で、プロの34〜46試合に対して分母が大きくなるため、本当に広いばらつきが割り戻されてしまいます。東京の1部は1.88と出て、これは平凡な値です。

観測分散は「戦力＋そのシーズン長が残すノイズ」なので、ノイズを引けばクラブの実像が戻ります。

```
sd_talent = sqrt(sd_observed² − sd_ideal²)
```

**この分解は新しいものではありません。** Tango と Mauboussin のもので、サッカーでは James Grayson と Martin Eastwood がプレミアリーグに適用済みです。`compare.py` に手法の新規性は一切ありません。**新しいのは、公開されている比較研究が対象にしていないリーグに当てていること**だけです。

**予測可能性。** [予測モデル](PREDICTION.ja.md)がクラス事前分布からどれだけ下に行けるか（nats）。半減期を**選んでいない**2シーズンで採点します。全リーグで同一の推定器を、再実装せず import して使います。

## このリポジトリが持っている部分

`compare` は、この連盟の各部を**それぞれ独立したリーグとして**測ります。部は決して混ぜません。ピラミッドを1つのものとして測ると、それが報告するのは**階層間の差**であって、どのリーグの内部の均衡でもないからです。混ぜたことが、この文書が記録している最初の誤答を生みました。

| 部 | チーム | 試合/チーム | 戦力差 | Noll-Scully | 引き分け | 得点 | 改善 |
|---|---|---|---|---|---|---|---|
| 1部 | 12 | 21 | 0.175 | 1.88 | 17.6% | 3.06 | +0.212 |
| 2部 | 12 | 18 | 0.172 | 1.78 | 15.0% | 3.47 | +0.055 |
| チャレンジリーグ | 11 | 13 | 0.220 | 1.88 | 11.5% | 4.62 | +0.164 |

3部は3シーズン、4部は28試合しかありません。**雑に測るくらいなら測らない**方針です。

## 参照セット

`docs/reference-leagues.json` に、欧州のプロ22部門（2021/22〜2025/26）が1件8数値で入っています。**これはリーグに関する派生統計であって、誰かの試合データの複製ではありません** — [DATA_POLICY.ja.md](DATA_POLICY.ja.md) が選手について引いているのと同じ線です。

作成元は [football-data.co.uk](https://www.football-data.co.uk/)（`robots.txt` は `Disallow:` が空、つまり全面許可）で、このパッケージの `compare.measure` をそのまま各部門に走らせています。**取得コードはこのリポジトリに入れていません。** 1つの出典について慎重であることを論じている[出典選定](SOURCE_SELECTION.ja.md)を持つプロジェクトに、第三者サイト向けのスクレイパをもう一式置くのは筋が通りません。`{talent_spread, gain}` の並びであれば、どんな参照セットでも `--reference` で使えます。

1部リーグ群と下部リーグ群の傾きは 1.013（se 0.505）と 0.438（se 0.283）で、差は t = 0.99。1本の線で足りるので単一のバンドとして扱っています。各n=11なので検出力は低く、**「区別できない」であって「同一」ではありません。**

## 分かったこと

参照22リーグだけで当てはめた線：

```
gain = −0.0924 + 1.257 × spread     r = +0.857, R² = 0.735, 残差sd 0.0223
```

**予測可能性はほぼ「クラブがどれだけ離れているか」の関数です。** プロ部門の分散の4分の3が、どんなサッカーをしているかに触れずに説明できます。

**撤回が2件あります。どちらもサンプルを広げた結果です。** 結果そのものより、このパターンの方が重要なので残してあります。

*東京のリーグは外れ値ではない。* 4部を1つのリーグに混ぜると線から残差2.54sd上に見えましたが、部ごとに分けると平均残差は **−0.08 sd** です。混ぜた値が膨らんでいたのは、採点対象の試合はすべて同一部内なのに、事前分布だけ4階層の全体で取っていたからです。

*学生サッカーは予測しやすくない。* NCAAの53カンファレンスと、日本の大学ピラミッドの残り（関東1部・2部、関西1部、九州1部。出典は [soccer-db.net](https://soccer-db.net/)、禁止は `/player/` と `/compare/` のみ）を加えて測ったところ、**関東1部 — 日本の大学サッカーの頂点 — はプロの帯の中に入りました。** 戦力差0.086（プロは0.054〜0.157）、改善+0.044（プロ平均+0.040）。関東2部と関西1部も同様です。日本の大学7リーグの平均残差は **+0.65 sd** で、これはノイズです。

**再現したもの: 学生の試合は決着しやすい。** 学生60リーグ中46が、プロの最低引き分け率23.9%を下回ります。両国で成立し、NCAAの延長戦ルールを補正しても残ります。ただし**水準が上がるほど薄れます** — 関東1部は21.0%・3.03得点でほぼプロの形、チャレンジリーグは11.5%・4.62でそうではない。したがってこれは**競技の水準の性質**であって、選手が学生であることの性質ではありません。

**否定的な結果: 学生リーグの記憶は短くない。** [PREDICTION.ja.md](PREDICTION.ja.md) が「毎年メンバーが入れ替わるから」と説明していた半減期は、東京の各部で250日、プロでも250日です。23リーグ全体で選ばれる半減期は120〜4000日に散らばり、**戦力差との関係はありません**（対数で r = −0.208）。減衰はどこでも効果的ですが、ここで短くすべき根拠はありません。

## 主張してよい範囲

「学生サッカーは〜である」は**言えません。** 母集団はこの地図のほぼ全域に広がっていて、その上端はプロと区別がつきません。主張できるのは**仕組みと位置づけ**です — 大学リーグは、プロとして読める関東1部から、そうではないチャレンジリーグまでの幅を持つ、ということ。

試合の形の結果について、**機構は示せていません。** 残差と1試合得点の相関は+0.219、引き分け率とは−0.289（78リーグ）で、数字と整合する仮説であって、数字が示した機構ではありません。

ホームアドバンテージは**全比較から除外**しています。football-data は全試合でホストを明示し、この連盟のAPIは一度も記録せず会場の使用実績から59%を推定しており（自前グラウンドを持つクラブに偏ります）、3つ目の出典は記録自体がありません。**別々の測定を1つの列に並べるべきではありません。**
