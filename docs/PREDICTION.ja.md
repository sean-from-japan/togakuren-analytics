# 予測

このリポジトリの他の文書は、起きたことを記述している。この文書だけは、まだ起きていない
ことについて主張する。したがって信じてもらうためではなく、検証できるように書いてある。
各モデルはクラスpriorと比較して、見ていない試合で採点する。設定は2022〜2024年だけで
決めて以降触っていないので、下の2025〜2026年の数字はすべて標本外である。

```bash
togakuren backtest --league-only --until 2024   # 下の調整区間の表
togakuren backtest --league-only --start 2025   # 下の標本外の表
togakuren forecast --series "2026 1部"          # 残り試合の予測
```

## モデル

| | |
|---|---|
| `prior` | 3つの結果の出現頻度。他のすべてはこれを上回らなければ意味がない。 |
| `elo` | クラブごとに1つのレーティング。結果と得失点差で動かす。 |
| `poisson` | クラブごとの攻撃力・守備力を重み付き最尤法で推定し、スコア分布に変換する。 |

ポアソンの推定は座標上昇法で、各パラメータに閉形式の更新式がある。依存パッケージが
1つも無いこのツールに、依存を1つも足さずに済む。

## 採点方法

必ず walk-forward で行う。各試合は、それより前に行われた試合だけを使って予測し、
そのあとでモデルに渡す。ランダム分割では未来が漏れる —— 3月のチーム力は1月について
何かを語ってしまう —— のでどのモデルも実力以上に見える。テストの1つは、モデルが
予測前にその試合を見せられていないことを検証するためだけに存在する。

主指標は3値の対数損失（nats、小さいほど良い）で、超えるべき基準は prior である。
正解率も併記するが、読みやすいからであって有益だからではない。接戦を全部本命側に
丸めれば正解率は上がり、肝心なところは悪化する。

## 結果

リーグ戦のみ。設定は最初のブロックで決め、以降は見直していない。

**調整区間 2022〜2024（n = 1,090）**

| モデル | 対数損失 | Brier | 正解率 |
|---|---|---|---|
| prior | 1.0090 | 0.6150 | 42.0% |
| elo | 0.8649 | 0.5022 | 62.9% |
| poisson | 0.8311 | 0.4779 | 66.3% |

**標本外 2025〜2026（n = 525）**

| モデル | 対数損失 | Brier | 正解率 |
|---|---|---|---|
| prior | 1.0200 | 0.6204 | 44.6% |
| elo | 0.8753 | 0.5099 | 61.3% |
| **poisson** | **0.8192** | **0.4750** | **65.7%** |

サッカーのリーグとしては prior が高い。引き分けが少ないからで、完了2,184試合のうち
15.5%しかない（プロではおよそ4分の1）。大学の2チームがプロの2チームより互角になり
にくいということであり、モデルがここまで当たる理由も同じである。

## 効果があったのはどれか

各行はフルモデルから1つだけ外したもの。標本外2025〜2026のリーグ戦。

| 構成 | 対数損失 | 変化 |
|---|---|---|
| poisson | 0.8192 | — |
| Dixon-Coles項なし | 0.8211 | +0.002 |
| ホーム項なし | 0.8268 | +0.008 |
| **時間減衰なし** | **0.9137** | **+0.095** |

**時間減衰が本体である。** 4年前の試合を先月の試合と同じ重みで扱うモデルは、Elo より
悪い。半減期180日で重み付けすることの価値が、他のすべての改良を合わせたものより大きい。
毎年4月にチームを作り直す競技であれば、そうなるのが当然である。

**「前シーズンがどれだけ引き継がれるか」は再現しなかった。** Elo にはシーズン境界で
レーティングを平均に引き戻す割合のパラメータがある。2022〜2024では半分残すのが、
全部残す（0.8917）よりも全部捨てる（0.8681）よりも明確に良かった（0.8649）。ところが
2025〜2026では順序が逆転し、全部捨てるのが勝った（0.8676 対 0.8753）。区間が2つ、
答えも2つなので、ここに答えは無い。両方で成立するのは上の連続的な減衰だけである。

## ホームアドバンテージ

APIは試合ごとに会場を記録するが、どちらが主催かは記録しない。そこでホームは推定する。
3回以上使われ、その75%以上に同じクラブが関わっている会場を、そのクラブのグラウンドと
みなす。これで完了2,184試合のうち**1,015試合**にホームが特定できる。残りは中立扱いで、
実際に中立の会場も多い。

ホームが特定できる試合では、ホーム側が45.5%勝ち、18.9%引き分け、35.6%負ける ——
**1試合あたり勝点1.555 対 1.256**。推定されたモデルはこの効果を得点率+13.5%と見る。

ただし予測項としての価値は、この数字ほど大きくない。半分未満の試合にしか適用されず、
標本外区間の改善は0.008 natsで、調整区間ではごくわずかに**マイナス**だった。結果として
測定でき、機序としても妥当なので残してあるが、予測がこれを必要としているわけではない。

## 部別

標本外2025〜2026、同じ試合に対する prior との比較。

| 部 | n | poisson | prior |
|---|---|---|---|
| 1部 | 210 | 0.8273 | 1.0273 |
| 2部 | 150 | 0.9478 | 1.0513 |
| 3部 | 135 | 0.7031 | 0.9861 |
| チャレンジリーグ | 30 | 0.6425 | 0.9641 |

2部がこのリーグで最も予測しにくく、その差は小さくない。prior からの改善幅は3部の
半分以下である。[FINDINGS.ja.md](../FINDINGS.ja.md) の決定率の異常も2部の話で、
そちらも未解明であり、符合している。

3行目に注目してほしい。桜美林大学は勝点で2位、予測では3位で、1点上回っている相手に

作る唯一の理由である。

シミュレーションで引くのは各試合の結果だけでスコアは引かないので、勝点が並んだ場合は
既に持っている得失点差で順序をつけている。順位表を並べるには十分だが、得失点差を
引用できる精度ではない。

## やらないこと

- **xGは無い。** 連盟が記録しているのはシュートの**本数**であって位置ではない。
  チャンスの質はここには無く、この文書のどの数字もxGとして読んではいけない。
- **選手情報は使っていない。** 負傷・出場停止・選手起用はモデルに入っていない。
  データ自体は試せるだけのものを持っているが、入れていない。
- **選手単位の予測はしないし、今後もしない。** アマチュアの学生個人を予測することは
  プロファイリングであり、[DATA_POLICY.ja.md](DATA_POLICY.ja.md) はここにも同じように
  適用される。上のすべての数字はチーム単位の集計である。
- **日程未定の試合**は、連盟が日程を決めるまでシーズンの仮日付を持ち続ける
  （2026年8月時点で残り128試合中73試合）。過去の試合として扱わず `TBC` と表示する。
