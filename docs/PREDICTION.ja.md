# 予測

*[English](PREDICTION.en.md)*

他の文書は過去の試合を分析していますが、この文書では未消化試合を予測します。
再現可能性を確保するため、各モデルをクラス事前分布と比較し、学習に使っていない試合で評価します。
設定は2022〜2024年だけで決め、その後は変更していません。以下の2025〜2026年の数値は
すべて標本外評価です。

```bash
togakuren backtest --league-only --until 2024   # 下の調整区間の表
togakuren backtest --league-only --start 2025   # 下の標本外の表
togakuren forecast --series "2026 1部"          # 残り試合の予測
togakuren dashboard --series "2026 1部" --forecast   # 同じ予測をチームごとにHTMLで表示
```

以下の評価には考慮できていない点が1つあります。**このリーグは2023年に神奈川県大学リーグと統合し、
クラブの顔ぶれもそこで入れ替わっている**ため、調整区間は大会の入れ替わりをまたいでいます
（[LEAGUE_STRUCTURE.ja.md](LEAGUE_STRUCTURE.ja.md)）。半減期180日は、2023年以降を予測する
時点で2022年の重みを大きく下げるため影響は小さいと考えられます。ただし、これは再編を明示的に
補正した結果ではありません。統合が評価値に与えた影響は未検証です。

## モデル

| | |
|---|---|
| `prior` | 3つの結果の出現頻度。他のすべてはこれを上回らなければ意味がありません。 |
| `elo` | クラブごとに1つのレーティング。結果と得失点差で動かします。 |
| `poisson` | クラブごとの攻撃力・守備力を重み付き最尤法で推定し、スコア分布に変換します。 |

ポアソンの推定は座標上昇法で、各パラメータに閉形式の更新式があります。依存パッケージが
1つも無いこのツールに、依存を1つも足さずに済みます。

## 採点方法

採点は必ず walk-forward で行います。各試合は、それより前に行われた試合だけを使って予測し、
そのあとでモデルに渡します。ランダム分割では未来が漏れる —— 3月のチーム力は1月について
何かを語ってしまう —— ので、どのモデルも実力以上に見えてしまいます。テストの1つは、
モデルが予測前にその試合を見せられていないことを検証するためだけに存在します。

主指標は3値の対数損失（nats、小さいほど良い）で、超えるべき基準は prior です。
正解率も併記していますが、読みやすいからであって有益だからではありません。接戦を全部
本命側に丸めれば正解率は上がり、肝心なところは悪化します。

記号の意味は次のとおりです。**対数損失**は、実際に起きた結果へどれだけ高い確率を割り当てられたか
を測ります。自信を持って外すほど大きくなるので、小さいほど良い値です。**nats** は自然対数を
使ったときの単位で、0.102 nats の悪化は「実際に起きた結果への確率が平均10%ほど低くなった」に
相当します。**Brier** は同じ予測を二乗誤差で測ったもので、0から2までの値を取り、これも小さい
ほど良い値です。**prior** はその時点までの勝ち・引き分け・負けの出現頻度をそのまま予測に使う
モデルで、これを上回れなければ学習させた意味がありません。表の **n** は試合数です。

## 結果

リーグ戦のみを対象にしています。設定は最初のブロックで決め、以降は見直していません。

**調整区間 2022〜2024（n = 1,090）**

| モデル | 対数損失 | Brier | 正解率 |
|---|---|---|---|
| prior | 1.0090 | 0.6150 | 42.0% |
| elo | 0.8650 | 0.5022 | 62.9% |
| poisson | 0.8311 | 0.4779 | 66.3% |

**標本外 2025〜2026（n = 597、2026-09-27の試合まで）**

| モデル | 対数損失 | Brier | 正解率 |
|---|---|---|---|
| prior | 1.0174 | 0.6190 | 44.9% |
| elo | 0.8672 | 0.5042 | 61.6% |
| **poisson** | **0.8211** | **0.4748** | **65.7%** |

サッカーのリーグとしては prior が高くなっています。引き分けが少ないからで、完了2,256試合の
うち15.4%しかありません（プロではおよそ4分の1）。大学の2チームはプロの2チームより互角に
なりにくいということで、モデルがここまで当たる理由も同じです。

## 効果があったのはどれか

各行はフルモデルから1つだけ外したものです。標本外2025〜2026のリーグ戦を対象にしています。

| 構成 | 対数損失 | 変化 |
|---|---|---|
| poisson | 0.8211 | — |
| Dixon-Coles項なし | 0.8238 | +0.003 |
| ホーム項なし | 0.8312 | +0.010 |
| **時間減衰なし** | **0.9227** | **+0.102** |

**最も大きく寄与したのは時間減衰です。** 4年前の試合を先月の試合と同じ重みで扱うと、
モデルの成績はEloより悪くなります。半減期180日の重み付けによる改善幅は、他の変更を
合計した改善幅より大きい結果でした。

**「前シーズンがどれだけ引き継がれるか」は再現しませんでした。** Elo にはシーズン境界で
レーティングを平均に引き戻す割合のパラメータがあります。2022〜2024では半分残す設定が、
全部残す（0.8918）よりも全部捨てる（0.8681）よりも明確に良い結果でした（0.8650）。ところが
2025〜2026では順序が逆転し、調整区間で最も悪かった「全部残す」設定が最も良い結果でした
（0.8606。半分残すと0.8672、全部捨てると0.8709）。
区間によって結果が異なるため、一貫した結論は出せません。両方の区間で成立するのは、上記の
連続的な時間減衰だけです。

## ホームアドバンテージ

APIは試合ごとに会場を記録していますが、どちらが主催かは記録していません。そこでホームは
推定します。3回以上使われ、その75%以上に同じクラブが関わっている会場を、そのクラブの
グラウンドとみなしています。これで完了2,256試合のうち**1,072試合**にホームが特定できます。
残りは中立扱いで、実際に中立の会場も多くあります。

ホームが特定できる試合では、ホーム側が46.1%勝ち、18.6%引き分け、35.4%負ける ——
**1試合あたり勝点1.568 対 1.246**。2026-09-28時点で推定したモデルは、この効果を得点率+15.9%と
見ています。

ただし予測項としての価値は、この数字ほど大きくありません。半分未満の試合にしか適用されず、
標本外区間の改善は0.010 nats、調整区間ではごくわずかに**マイナス**でした。結果として測定でき、
機序としても妥当なので残していますが、予測がこれを必要としているわけではありません。

## 記録として残す予測

予測は作成日を付けて残し、あとから作り直しません —— 黙って更新される予測は予測ではない
からです。新しい結果が入ったら、前の予測を当時のモデルのまま採点し、そのうえで新しい日付の
予測を追加します。

### 読み方の注意

シミュレーションで生成するのは各試合の勝ち・引き分け・負けだけで、スコアは生成しません。
勝点が並んだ場合は、シミュレーション開始時点の得失点差で順位を決めています。そのため、
予測順位の比較には使えますが、最終的な得失点差の予測には使えません。

## やらないこと

- **xGはありません。** 連盟が記録しているのはシュートの**本数**であって位置ではありません。
  チャンスの質はここには無く、この文書のどの数字もxGとして読まないでください。
- **選手情報は使っていません。** 負傷・出場停止・選手起用はモデルに入れていません。
  データ自体は試せるだけのものがありますが、使っていません。
- **選手単位の予測はしませんし、今後もしません。** アマチュアの学生個人を予測することは
  プロファイリングにあたり、[DATA_POLICY.ja.md](DATA_POLICY.ja.md) はここにも同じように
  適用されます。上のすべての数字はチーム単位の集計です。
- **日程未定の試合**は、連盟が日程を決めるまでシーズンの仮日付を持ち続ける
  （2026年8月時点で残り128試合中73試合、2026-09-28時点では2026年リーグ戦の残り54試合中
  12試合）。過去の試合としては扱わず、`TBC` と表示します。
