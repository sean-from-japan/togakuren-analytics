# なぜこのリーグなのか

日本の大学サッカーはピラミッド構造になっている。下から県リーグ、その上に地域リーグ、
頂点に全国大会がある。このプロジェクトが読んでいるのはその1段、東京都大学サッカー連盟
（東京都と神奈川県の大学リーグを主催）だけである。これは選択であり、議論ではなく確認
できる2点で決めた。**各連盟が実際に何を公開しているか、そしてプログラムに読まれることに
ついてサイト自身が何と書いているか。**

確認日: 2026-09-01

## この連盟が公開しているもの

| | |
|---|---|
| 取得経路 | Cockpit CMS からの JSON。HTMLを解析しないので、ページの見た目が変わっても壊れない。 |
| 深さ | スタメン、ベンチ、時刻付き交代、反則コード付きカード、選手別・期間別シュート数、登録名簿。 |
| 期間 | 2021年以降 2,312試合。選手単位の記録は2022年から。 |
| `robots.txt` | 禁止しているのは `/wp-admin/` のみ。 |

分析を成立させているのはこの深さである。[FINDINGS.ja.md](../FINDINGS.ja.md) の結果 ——
昇格の代償、学年の検証、順位とシュート数の乖離 —— はいずれも複数シーズンぶんの
試合単位の記録を必要とする。順位表だけからは1つも出てこない。

## ひとつ上の段: 関東大学サッカーリーグ

このプロジェクトを広げる最も自然な方向は上、関東大学サッカーリーグである。36大学、
水準も上で、このデータセットのいくつかのクラブが目指している場所でもある。ここでは
扱っていない。理由は難易度とは関係がない。

連盟自身のサイト `jufa-kanto.jp` はクロールを許可している（`Allow: /`）。しかし
結果・順位表・星取表・得点・アシスト・警告リストへのリンクは、**2012年から2026年まで
どのシーズンも**第三者のリーグ管理システム `football-system.jp` を指しており、
そのホストの `robots.txt` はこうなっている。

```
User-agent: *
Disallow: /
```

これで決まりである。公開と再配布は別だ、という主張を土台にしているリポジトリが、
「プログラムは入るな」と書いてあるサイトを無視してよいわけがない。

判断を楽にする（難しくするのではなく）事実がもう2つある。

- そのシステム上の日程・結果一覧に載っているのは**スコアだけ**である。試合ごとの
  記録ページが存在しないので、このプロジェクトの土台である出場・出場時間・シュート数は
  そもそも取得しようがない。
- 連盟は自前のサイトに今季のマッチレポートを公開しており、結果・得点者に加えて、
  東京都のデータには無いホーム/アウェイの明示まである。ただし今季だけで、過去年度は
  404 を返す。1シーズンぶんの結果と得点者では、上記のどの分析も拡張できない。

そのデータがどうしても必要になったときの筋は、`Disallow` を回避することではなく、
連盟に依頼することである。

## 下の段と隣の段

神奈川県大学サッカーリーグは順位表をプレーンなHTMLで公開しており、クロール制限も無いが、
順位表しか無い。試合単位の記録が無いので、ここで扱える材料にはならない。

## 残るもの

調べた限り、日本の大学サッカーを試合単位で扱っているオープンソースは存在しない。
定評のあるサッカーデータライブラリはプロリーグの集約が対象で、ここまで降りてこない。
つまりピラミッドの中で、分析に足る深さがあり、かつプログラムに読まれることを許して
いる段はちょうど1つで、これはその段のための道具である。

これは「研究対象として最良のリーグ」よりも狭い主張だが、こちらが正直な言い方である。
